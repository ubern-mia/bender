# The episodes

Nine episodes, in the order a project actually happens: get the data, learn to talk about
it, train something, work out whether it is any good, work out *why* it does what it does,
then the architectures and the newer ideas — segmentation, generation, foundation models,
and training across hospitals that cannot share data.

They stand alone, but they were written to be watched in order, and later episodes
deliberately call back to earlier ones.
